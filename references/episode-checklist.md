# Episode review record

Copy this into the episode folder and add links or timecodes as evidence. Leave a box open when the check has not happened.

- [ ] Source video, transcript, existing approved cut, destination, and requested changes identified.
- [ ] Story beats map each new point to the footage, case evidence, or explanatory visual that shows it.
- [ ] For a new visual direction: episode-specific frames and a 15–20 second representative cut reviewed. For a local revision: changed area previewed.
- [ ] Captions, names, translations, rights, and illustrative footage boundaries checked.
- [ ] Narration, picture, captions, animation, source audio, music, chapters, and sound cues share the intended timeline.
- [ ] Music and effects auditioned with real speech; cue density and seams checked.
- [ ] Full render completed without replacing an earlier playable version; technical checks recorded.
- [ ] Final file watched and listened to continuously; independent review and user acceptance recorded separately when applicable.
- [ ] Video, captions, editable project, asset notes, and concise retrospective archived.
